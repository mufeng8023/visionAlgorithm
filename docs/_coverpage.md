# visionAlgorithm

> 基于 C++17 的轻量级 YOLO 系列模型推理框架

- 模块化设计, 模型加载、推理、后处理完全解耦
- 支持 YOLOv5 / v8 / v26 目标检测与姿态估计
- 基于 OpenCV DNN 后端, 兼容 CPU / GPU 推理
- 内置多线程安全日志系统与高性能计时器
