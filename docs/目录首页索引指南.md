# 📑 目录首页索引指南

> **本文档帮助你理解如何在多子目录、多文件的 docsify 文档站点中组织索引和导航。**

---

## 一、你的场景

你有一个 `docs/` 目录，下面有很多子目录，每个子目录下有多个 `.md` 文件：

```bash
docs/
├── index.html              # 站点入口
├── README.md               # 首页内容
├── _sidebar.md             # 侧边栏导航配置
├── _coverpage.md           # 封面页（欢迎屏）
│
├── getting-started/        # 子目录：快速入门
│   ├── installation.md
│   ├── quickstart.md
│   └── configuration.md
│
├── tutorials/              # 子目录：教程
│   ├── basics.md
│   ├── advanced.md
│   └── faq.md
│
├── api/                    # 子目录：API 参考
│   ├── overview.md
│   ├── module-a/
│   │   ├── index.md        # ← 子目录的"首页索引"
│   │   ├── api-auth.md
│   │   ├── api-users.md
│   │   └── api-posts.md
│   └── module-b/
│       ├── index.md        # ← 子目录的"首页索引"
│       ├── api-files.md
│       └── api-search.md
│
└── tools/                  # 子目录：工具
    ├── index.md
    └── resources.md
```

---

## 二、三种索引方案

根据你文档页面的数量，选择最适合的方案：

### 方案一：侧边栏直接展开全部页面

**适用场景：** 页面总数 < 30 页，结构简单

**做法：** 在 `_sidebar.md` 中用嵌套列表把每个页面都列出来。

**示例 `_sidebar.md`：**

```markdown
- 📖 开始阅读
  - [首页](README.md)
  - [前言](preface.md)

- 🚀 快速入门
  - [安装指南](getting-started/installation.md)
  - [快速开始](getting-started/quickstart.md)
  - [基础配置](getting-started/configuration.md)

- 📚 核心教程
  - [基本用法](tutorials/basics.md)
  - [进阶技巧](tutorials/advanced.md)
  - [常见问题](tutorials/faq.md)

- 🧩 API 参考
  - [API 概览](api/overview.md)
  - [认证 API](api/module-a/api-auth.md)
  - [用户 API](api/module-a/api-users.md)
  - [文章 API](api/module-a/api-posts.md)
  - [文件 API](api/module-b/api-files.md)
  - [搜索 API](api/module-b/api-search.md)
```

**优点：** 所有页面一眼可见，导航方便  
**缺点：** 页面多了侧边栏会很长

---

### 方案二：章节分组 + 关键页链接（⭐ 推荐）

**适用场景：** 页面总数 30~100 页，有清晰的章节划分

**做法：** 侧边栏按章节分组，每个章节列出 3~5 个关键页面。每个子目录下创建 `README.md`（或 `index.md`）作为该章节的索引页，列出完整页面清单。

**示例 `_sidebar.md`：**

```markdown
- 📖 **开始阅读**
  - [首页](README.md)
  - [前言](preface.md)

- 🚀 **快速入门**
  - [安装指南](getting-started/installation.md)
  - [快速开始](getting-started/quickstart.md)
  - [基础配置](getting-started/configuration.md)

- 📚 **核心教程**
  - [基本用法](tutorials/basics.md)
  - [进阶技巧](tutorials/advanced.md)
  - [常见问题](tutorials/faq.md)

- 🧩 **API 参考**
  - [API 概览](api/overview.md)
  - [📋 认证与用户](api/module-a/index.md)
  - [📁 文件与搜索](api/module-b/index.md)

- 🛠 **工具与资源**
  - [📋 工具链索引](tools/index.md)
  - [外部资源](resources.md)
```

**子目录索引页示例 `api/module-a/index.md`：**

```markdown
# 📋 认证与用户 API

本模块提供认证和用户管理相关的 API 接口。

## 📄 接口列表

| 接口名称 | 说明                       | 链接                         |
| -------- | -------------------------- | ---------------------------- |
| 认证 API | 用户登录、注册、Token 管理 | [api-auth.md](api-auth.md)   |
| 用户 API | 用户信息增删改查           | [api-users.md](api-users.md) |
| 文章 API | 文章发布与管理             | [api-posts.md](api-posts.md) |

## 🔗 相关文档

- [API 总览](../overview.md)
- [文件与搜索 API](../module-b/index.md)
- [常见问题](../../tutorials/faq.md)
```

**优点：** 侧边栏简洁，子目录索引页提供完整列表  
**缺点：** 需要多点击一次才能看到完整页面列表

---

### 方案三：按文件夹分组 + README 索引页

**适用场景：** 页面总数 > 100 页，层级深，结构复杂

**做法：** 与方案二类似，但更加依赖子目录的 `README.md` 作为索引。侧边栏只到目录层级，每个目录点进去是完整的索引页。

**优点：** 侧边栏最简洁，适合超大型文档  
**缺点：** 导航层级深，访客需要多点几次

---

## 三、三种方案的对比

| 特性         | 方案一（展开） | 方案二（分组⭐） | 方案三（目录） |
| ------------ | :------------: | :-------------: | :------------: |
| 侧边栏长度   |      很长      |      适中       |       短       |
| 查找页面速度 |       快       |       中        |     慢一点     |
| 适合页面数   |      < 30      |     30~100      |     > 100      |
| 维护成本     |       高       |       中        |       低       |
| 访客体验     |      ★★★★      |      ★★★★★      |      ★★★       |

## 四、子目录索引页编写模板

在每个子目录下创建一个 `README.md` 或 `index.md`，使用以下模板：

```markdown
# 📋 [章节名称] 索引

> 一段简短描述，介绍本章节包含的内容。

## 📄 文档列表

### [子分类一]

| 文档名称 | 说明     | 链接                           |
| -------- | -------- | ------------------------------ |
| 文档A    | 简要描述 | [document-a.md](document-a.md) |
| 文档B    | 简要描述 | [document-b.md](document-b.md) |

### [子分类二]

| 文档名称 | 说明     | 链接                           |
| -------- | -------- | ------------------------------ |
| 文档C    | 简要描述 | [document-c.md](document-c.md) |
| 文档D    | 简要描述 | [document-d.md](document-d.md) |

## 🔗 相关章节

- [上一级目录](../README.md)
- [相关章节链接](../other-section/index.md)
```

## 五、实操步骤

### 步骤 1：规划文档结构

在 `docs/` 下创建子目录，按逻辑分组：

```
docs/
├── getting-started/   ← 新手入门
├── tutorials/         ← 使用教程
├── api/               ← API 文档
│   ├── auth/          ← 认证相关
│   └── data/          ← 数据相关
├── guides/            ← 操作指南
└── reference/         ← 参考资料
```

### 步骤 2：编写 `_sidebar.md`

参考方案二（推荐），按 Emoji 分组：

```markdown
- 📖 开始
- 🚀 快速入门
- 📚 教程
- 🧩 API
- 📘 指南
- 📎 参考
```

### 步骤 3：为每个子目录创建索引页

在每个子目录下创建 `README.md`（或 `index.md`），列出该目录下的所有页面。

### 步骤 4：在 `index.html` 中配置

```javascript
window.$docsify = {
  homepage: 'README.md',
  loadSidebar: '_sidebar.md',
  // ...
};
```

### 步骤 5：本地预览（可选）

```bash
npx docsify serve docs
```

## 六、常见问题

### Q: 侧边栏中的链接是相对于哪个目录的？

A: 所有链接都是相对于 `index.html` 所在的目录（即 `docs/`）。例如：
- `[首页](README.md)` → `docs/README.md`
- `[安装](getting-started/installation.md)` → `docs/getting-started/installation.md`

### Q: 子目录的索引页用什么文件名？

A: 推荐使用 `README.md`（docsify 的默认首页文件名），也可以用 `index.md`。在侧边栏中链接到它即可。

### Q: 如何让侧边栏自动折叠/展开？

A: docsify 默认会根据当前页面自动展开对应的侧边栏层级。你不需要额外配置。

### Q: 封面页和首页有什么区别？

A: 
- **封面页**（`_coverpage.md`）：访问网站时的欢迎屏，显示大标题和按钮，点击后才进入内容
- **首页**（`README.md`）：文档的实际首页内容，显示在侧边栏旁边的内容区

| 你要做的事     | 对应操作                                                                               |
| -------------- | -------------------------------------------------------------------------------------- |
| 添加新的子目录 | 1. 在 docs/ 下创建目录 2. 在子目录下创建 README.md 索引页 3. 在 _sidebar.md 中添加链接 |
| 添加新页面     | 1. 在对应子目录下创建 .md 文件 2. 更新该子目录的 README.md 索引表                      |
| 修改导航顺序   | 编辑 _sidebar.md 中列表的顺序                                                          |
| 添加封面页     | 1. 编辑 _coverpage.md 2. 在 index.html 中启用 coverpage 配置                           |
| 修改主题颜色   | 编辑 index.html 中 <style> 标签的 --theme-hue 变量值                                   |
