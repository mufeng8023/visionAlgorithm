# visionAlgorithm

## 项目站点说明

本文档站点基于 [docsify-themeable](https://github.com/jhildenbiddle/docsify-themeable.git) 主题框架构建。

- **docsify**: 基于 Markdown 的动态文档站点生成器;
- **docsify-themeable**: 由 [John Hildenbiddle](https://github.com/jhildenbiddle) 开发的可定制主题插件, 提供灵活的主题切换与样式扩展能力;

站点源代码位于 `docs/` 目录下, 通过 `docs/index.html` 入口文件加载配置与资源。
